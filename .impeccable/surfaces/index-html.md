# Surface brief: personal portfolio (one-page home + detail routes)

Scope: the whole static site. Visitor mode: **Experience** for the home page (the work leads from the first
viewport); the detail pages (case studies, work, about, stack, record, the gate in full) are **Read** pages.

## Audience, job, action, proof, constraints
- Hiring engineers, researchers and founders deciding in minutes whether this person builds real AI systems; then
  they verify. Action: try the gate in the first screen, open a case study, get in touch.
- Proof: the real projects and honest limits in PRODUCT.md. Nothing fabricated; private repos are labelled private;
  the invented example in the Sidequest exhibit is labelled "Example content".
- Constraints: static React/Vite on GitHub Pages (works under a subpath), WCAG 2.2 AA, `prefers-reduced-motion`,
  the gate demo is a labelled local simulation. Code-led build (no image generation here).

## Chosen direction
The owner's three references pinned the direction (tamalsen.dev: dark with a huge wordmark; ewan-kerboas.fr: big
type that lights as it passes; robbowen.digital: a personal first sentence), so Impeccable's roll was run and not
built: seed key dfcfde5e, assigned index 4, challengers wuxia painted hoarding, Du Bois data portraits, black-hole
accretion disk, Miura-fold sheet, ebru floated pigment, seven-segment display. None was weighed in depth. The
tasteskill direction is "the name as a monument" (seed 1319895359). Memorable moment: a visitor sends an action
and the project's own rule engine allows it, denies it or holds it for them.

## Direction contract
THESIS: The name is the headline and the owner's own safety gate is the picture. The page proves the mechanism it
claims in the first screen instead of describing it. It refuses the dark-glow AI page, the card grid and the civil
engineering costume of the earlier previews.
OWN-WORLD: Graphite ground, one cobalt field, one pale field, safety orange on the single action and on whatever the
gate stopped. Chivo only, black weight in capitals for the name, project names and section words, regular weight for
reading. Square corners, no hairlines, no shadows, no gradients, no monospace outside code. State is a shape plus a
word, never colour alone. Recognisable with all content removed: a giant cropped name and a doorway-shaped gate.
STORY: The visitor understands in seconds that this person engineers gated, auditable AI systems, believes it
because the gate rules on a request in front of them and each project shows its result beside its limit, and then
opens a case study or writes.
FIRST VIEWPORT: A thin bar, a line that says what the gate is doing with a "Send an action" control, one orange
"See my work" action at the top right, a doorway-shaped gate in the middle with requests drifting toward it, and the
name LIANG fitted to the full width of the screen along the bottom with one sentence beneath it.
FORM: Name as a monument, with a dark-room ground; ordered list position 4 (pinned by the references); seed key
dfcfde5e.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
